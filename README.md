# A2_COMP371

To set up OpenGL for this project, please follow the setup (**setup.md** please do not modify this file. Use it as a setup guide on your machine).
Also, make sure to install GLM and have the MSYS2 compiler

**To start the assignment (i.e. see the graphics):** </br>
1- Build with OpenGL <img width="779" height="384" alt="image" src="https://github.com/user-attachments/assets/de73eda8-0f6d-4126-9a83-af32e582db1a" /> </br>
2- Run the following command in your terminal: ./main.exe

Use the keys to apply transforms to the pyramid. If a camera perspective is required, uncomment the marked code.
